# PCA-TALLER-ALUMNOS

Repositorio de trabajo para los alumnos del **Taller PCA**. Aquí conviven tres áreas **independientes** entre sí (cada una se usa por separado, según lo que necesites):

---

## 1. `Taller-PCA/` — Material del taller

Documentos de estudio y trabajo del taller:

- `Syllabus/` — cronograma, especificación de la metodología y guía de adaptación de stack.
- `Presentaciones_Clase/` y `Presentaciones_Autoexplicativas/` — clases y temas de estudio.
- `Fundamentos_y_Comunicacion/` y `Arquitectura_y_Criterio/` — guías conceptuales.
- `Ejercicios_Nivelacion/` y `Ejercicios_Microtasks/` — laboratorios y ejercicios.
- `01_rubrica_evaluacion_arquitecto.pdf` — rúbrica de evaluación.

## 2. `AutoEstudioAsistido/` — Estudia con IA, a tu manera

Prompts para estudiar con cualquier IA (ChatGPT, Claude, Gemini, etc.) adaptándose a tu forma de aprender. **Es material de estudio: no se copia a tus proyectos ni tiene relación con el kit de configuración.**

- `00_LEEME.md` — empieza aquí: orden de uso y flujo completo.
- `01_Prompt_Diagnostico_Perfil.md` — descubre tu perfil de aprendizaje.
- `02_Prompt_Generador_Friccion.md` — ejercicios con "fricción deseable" (sin perfil).
- `03_Plantilla_Estudio_Personalizado.md` — molde de tu archivo único de estudio.

**Flujo:** subes `01` + `03` → respondes el diagnóstico → recibes **un solo archivo** (`Mi_Estudio_TuMateria.md`) → con ese archivo estudias donde quieras.

## 3. `setup/` — Kit de configuración de proyectos

Plantillas, convenciones, prompts de workflow y la herramienta de anotaciones (`tools/pca_annotator.py`). **Esto sí se copia** a la raíz de tu proyecto de código antes de empezar a programar (ver `setup/README.md` y `setup/AGENTS.md`).

---

> **Regla mental:** `Taller-PCA` y `AutoEstudioAsistido` son para **aprender**. `setup/` es para **construir tu proyecto**. No mezcles las carpetas.
